# scoop-scx

Scoop bucket for [scx](https://github.com/spapient/scx) — 本地查询感知上下文压缩器（query-aware context compressor, zero-dependency Rust）。

## 安装

```powershell
scoop bucket add scx https://github.com/spapient/scoop-scx
scoop install scx/scx
```

## 更新

```powershell
scoop update scx
```

## Manifest

`bucket/scx.json` 使用 GitHub release 资产 + SHA256SUMS 自动提取校验和（checkver/autoupdate）。
